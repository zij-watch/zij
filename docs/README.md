# Docs

Start with the [README](../README.md). To rebuild every number, see [REBUILD.md](../REBUILD.md).

## docs/event: written during the event

| File | What it is |
|---|---|
| [DECISIONS.md](event/DECISIONS.md) | Every decision made during the event, one line each, with its time and its reason. Lines are never edited. |
| [VALIDATION.md](event/VALIDATION.md) | How well each of the six models predicts VIIRS from MODIS, per area and per test. Generated by `zij validate`. |
| [FINDINGS.md](event/FINDINGS.md) | What the record shows and what it cannot: the Nile Delta after the 2004 ban, the Delta since 2018, and one sentence per area. Generated by `zij findings`. |
| [SMALL_AREAS.md](event/SMALL_AREAS.md) | The rule for small drawn areas (own fit, blend, or raw counts only), checked on random boxes. Generated by `zij boxes`. |
| [DATA_CONTRACT.md](event/DATA_CONTRACT.md) | The format of the files the pipeline exports for the app: `index.json`, `areas/`, `method.json`, `findings.json`. |
| [CELLS_FORMAT.md](event/CELLS_FORMAT.md) | The format of the cell files: weekly counts per cell and satellite, from which the browser fits a drawn area. |
| [HOTSPOTS_FORMAT.md](event/HOTSPOTS_FORMAT.md) | The format of the hotspot files: the kept detections one by one, for the day view and the hotspots CSV. |
| [STUDIO.md](event/STUDIO.md) | The studio map at `/studio/map`: the map alone, set by the address, for recording the video. |
